# Tier One Sports Events — navy and gold
The supplied circular T1 badge is the visual source of truth. Do not redesign it. Original PNG retained; derived circular crop, resized icons and proposed horizontal lockups are replaceable. Lockups contain raster artwork, not a true vector master.

## Direction A — Premium Matchday (recommended)
Deep navy #1D2E3F, champagne gold #D9B76C, warm off-white #F7F5F0, ink #182838. Gold buttons with navy text; dark gold #806025 for text on white. Editorial sports photography, generous whitespace, confident typography, restrained borders. Use Barlow Condensed for headings and Inter for body with system fallbacks. No lime, bookmaker styling, metallic gradients across UI, or generic SaaS cards.

## Direction B — Hospitality editorial
Same palette and logo, more light backgrounds, restrained navy headlines, generous editorial spacing, understated gold rules. Suitable for corporate hospitality and bespoke trips. Use Georgia or a licensed editorial serif for selected headings only. Keep navigation and forms simple.

## Photography
Source licensed authentic stadium, rugby, motorsport, golf and group travel photography. Hero 2400×1000 with clear left-hand text area; cards 1200×900. Optimise WebP, add alt text and verify usage rights. No photos included; prototype uses an abstract stadium-inspired CSS motif.

## Usage
Original badge is the only supplied brand asset. Proposed colours, typography and horizontal lockups are not approved brand guidelines. Use badge.png or badge.webp for larger placements; icon PNGs and ICO for smaller sizes. Inspect small-size legibility; request original vector artwork later. Keep logo paths centralised for easy replacement. Test contrast and responsive layouts before launch.
